# 🏥 Virtual-Chikitsa – Telemedicine & Remote Care

Virtual-Chikitsa is a digital healthcare platform that connects patients with doctors through online appointment booking, video consultations, and digital prescriptions. It integrates ZEGOCLOUD for video communication and Razorpay for online payments to provide a convenient remote healthcare experience.

## ✨ Features

- 📅 Online doctor appointment booking
- 🎥 Real-time video consultations using ZEGOCLOUD
- 💊 Digital prescription management
- 💳 Online payments using Razorpay
- 🩺 Remote access to healthcare services
- 📱 User-friendly healthcare interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Video Consultation:** ZEGOCLOUD API
- **Payment Gateway:** Razorpay

*Update the technology stack if your implementation differs.*

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   ```

2. Move the project folder into your local server directory, such as `htdocs` in XAMPP.

3. Start Apache and MySQL using the XAMPP Control Panel.

4. Create a MySQL database and import the project's SQL file, if provided.

5. Configure the database connection and required API credentials in the appropriate configuration files.

6. Open the application in your browser:

   ```text
   http://localhost/<PROJECT_FOLDER>/
   ```

## 🔐 Environment Configuration

Configure your database credentials, ZEGOCLOUD settings, and Razorpay API keys before running the application. Never commit passwords, secret keys, or other sensitive credentials to GitHub.
